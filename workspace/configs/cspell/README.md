# CSpell Configs

`cspell/` is the workspace configuration area for shared spelling configuration.

The active spelling configuration currently lives at the repository root:

```text
cspell.json
```

This area may later contain reusable CSpell presets when the repository needs shared spelling configuration packages.

## Current status

The current workspace uses one root CSpell configuration.

Additional CSpell presets may be added here when shared spelling rules become necessary across packages, documentation, and scripts.
