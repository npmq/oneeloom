# ADR

`adr/` contains platform Architecture Decision Records.

This directory records architectural decisions that affect platform structure, boundaries, contracts, dependency direction, or long-term project evolution.

## Purpose

ADR documents may be used to record:

- accepted architectural decisions;
- rejected alternatives;
- trade-offs and constraints;
- reasons behind important structure choices;
- consequences for future development.

## Boundary

`adr/` is a decision record area.

It does not replace architecture documentation, implementation guides, module documentation, or code comments.

The role of `adr/` is to preserve why important architectural decisions were made.
