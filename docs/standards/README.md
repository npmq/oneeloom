# Standards

`standards/` is the documentation area for shared project standards.

`standards/` defines common rules that help keep code, documentation, package structure, and development workflows consistent across the project.

## Purpose

Standard documents may define rules for:

- naming conventions;
- code style;
- documentation style;
- testing expectations;
- package structure;
- repository checks;
- release preparation;
- contribution workflow.

## Boundary

`standards/` must remain a shared rules area.

It must not replace architecture documents, ADRs, module models, or practical guides.

The role of `standards/` is to define how project work should stay consistent over time.
