# Guides

`guides/` is the documentation area for practical workflows and usage-oriented explanations.

`guides/` helps contributors apply the platform architecture in real development scenarios without replacing architecture documents, ADRs, or module models.

## Purpose

`guides/` may include practical documentation for:

- setup flows;
- development workflows;
- package usage examples;
- service creation steps;
- testing and validation routines;
- operational notes for common tasks.

## Boundary

`guides/` must remain a practical documentation area.

It must not contain architecture decisions, module responsibility models, source-level contracts, or long-term platform standards.

The role of `guides/` is to describe practical workflows for working with the platform.
